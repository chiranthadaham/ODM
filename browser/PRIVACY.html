Open Download Manager — Privacy notice

ODM detects file and playable media links and sends downloads you choose to the Open Download Manager app installed on this computer.

Data handled: download and media URLs (which may contain access tokens), suggested filenames, file response metadata, and the source website origin. Response metadata is held briefly in browser memory to detect downloads. Selected download details are sent only to the local ODM app. The app contacts the download website and keeps its queue on this computer.

We do not collect cookies, passwords, analytics, advertising identifiers, or browsing history for unrelated purposes. No data is sent to an ODM server, sold, or used for advertising. Website operators receive the requests needed to download their files. Use only content you have permission to download; protected and browser-only streams may be unavailable.

Automatic capture starts after you accept. Turn it off in the extension popup at any time. Declining keeps native browser downloads. Revoking consent below stops capture and clears in-memory detection information. Remove the extension to clear its preferences; clear the app queue separately to remove its local records.

Permissions: website access and request metadata detect file/media links; Downloads hands file downloads to the app while retaining browser fallback; Native Messaging connects to the local app; Storage remembers your choices; Context Menus offers a download command. Firefox additionally uses blocking request interception to hand off a validated file before it finishes in the browser. Private-window requests are excluded.

Download URLs can identify you. Review the destination before starting a download. The application is a separate download and must be installed first.

ODM's use of information follows the Chrome Web Store User Data Policy, including its Limited Use requirements. This notice covers the extension and its local handoff, not the privacy practices of websites you visit.

Privacy notice updated 12 October 2026. For support, use the support contact on the official extension listing.
